# AusLAMP Buckling

Research project for 3D lithospheric modelling and buckling. The work is organised in stages, with a separate repository for each component.

## Stage — Mesh generation and field mapping

This stage prepares georeferenced lithospheric meshes and maps temperature and bulk water content onto them.

- [regional_model_development_V2](https://github.com/auslamp-buckling/regional_model_development_V2): automated mesh extrusion, field mapping and validation, with the existing FEniCSx diffusion workflow.
- [regional_model_development_V1](https://github.com/auslamp-buckling/regional_model_development_V1): **Legacy workflow**, forked from [the source repository](https://github.com/shaheryar9094/regional_model_development_V1).

## Contributions

Each repository records its contributors and maintainer. Changes to the maintained mesh workflow require Juan's review.
